# 一起去云南 · 三个人的慢旅行

这是一个无需构建步骤的静态网页，可直接用于 GitHub Pages。

提供 2026 年 11 月 5–9 日三位女生同行的丽江＋大理联游及大理、丽江、西双版纳四套备选行程，包含每日景点、交通、妆造拍摄和休息安排。

页面采用旅行手帐风格：四张目的地明信片用于切换方案，20 张每日行程卡片配有风景参考照片，时间安排与交通可展开阅读。

大理与丽江页签还提供 14 个图文备选：每个景点包含建议时长、体力强度、拍照风格、主行程替换方式，以及可展开的交通与游玩提醒。泸沽湖、虎跳峡单列为需要重排的长线；原五天行程不会自动叠加这些景点。

图片位于 `assets/images/`，已转换为 WebP；原始页面、来源与图片信息记录在 `assets/image-sources.json`，每日图片下方也提供来源链接。图片展示目的地风景，不代表出行当天的天气或季节状态。

## 本地查看

直接双击 `index.html`，或使用任意静态文件服务器打开项目根目录。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库并推送本项目文件。
2. 在仓库的 **Settings → Pages** 中，将 Source 设为 **Deploy from a branch**。
3. 选择 `main` 分支和 `/(root)` 目录后保存。
4. 等待部署完成，GitHub 会显示可分享的网站地址。

航班、动车、景区开放与预约信息会变化，页面中的交通时间为规划预估，预订和出发前请通过各方案末尾的官方入口复核。

联游页签整合丽江会合、泸沽湖两天一晚、下午转场大理、洱海与返程；沙溪及正式妆照列为需要取舍的候补。天气为 2026 年 11 月 3 日查询快照，页面注明来源与更新边界，非实时天气。
